# ✨ Holographic Hand FX

A real-time AI-powered hand tracking web application that brings cinematic superhero-inspired visual effects to your browser.

Using MediaPipe Hands and modern web technologies, the application detects hand gestures through your webcam and renders immersive visual effects inspired by Doctor Strange, Iron Man, Spider-Man, and Thor.

---

## 🚀 Features

- 🖐️ Real-time AI Hand Tracking
- 📷 Live Camera Integration
- 🔮 Doctor Strange Magic Circle
- ⚡ Thor Lightning Effect
- 🔴 Iron Man Repulsor Blast
- 🕸️ Spider-Man Web Shooter
- 🎬 Cinematic Particle Effects
- 💫 Smooth Animations
- ⚡ Fast Performance with Vite
- 🎨 Modern Responsive UI

---

## 📦 Installation

```bash
git clone https://github.com/your-username/Holographic-Hand-FX.git

cd Holographic-Hand-FX

npm install

npm run dev
```

---

## 🎮 How to Use

1. Start the development server.
2. Open the application in your browser.
3. Click **Start Camera**.
4. Allow webcam permission.
5. Perform supported hand gestures.
6. Watch superhero-inspired cinematic effects appear in real time.
